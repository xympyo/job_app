# Durable decisions

`docs/09_DECISIONS.md` is the durable decision log. Append entries; do not rewrite prior
decisions when a policy changes. Each entry must include:

- date;
- decision;
- rationale; and
- implications for data, agents or the product.

Permanent policy belongs there: graduation timing, evidence boundaries, CV routing,
research mutation limits, duplicate handling and the priority of applying over endless
optimization. Temporary vacancy facts do not belong there. Put those in a job/source,
research run or dated report with its verification time.
