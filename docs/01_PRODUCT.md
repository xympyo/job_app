# Product

**Does this directly help Find → Evaluate → Apply → Progress? If not, defer it.**

A private, responsive Personal Career Command Center for Moshe: the persistent
operational database connecting discovery, research, fit, CV selection, application
questions, assessments, recruiter interactions, interviews and outcomes. It is not
just a tracker and not a crawler. Moshe decides; AI recommendations are editable advice.

## V1 acceptance

Sign in on desktop/phone; add/import and review vacancies; understand fit and CV choice;
save/skip/prepare/apply; track flexible stages, questions, draft/final answers, next
actions, deadlines, interviews and outcomes; search history; return without data loss.
Include reusable companies, multiple sources, deduplication review, manual verification,
safe validation, JSON/CSV export, loading/error/empty states, documentation, SQL migrations,
per-user RLS, tests and a clean build. Preserve the original vacancy at application time.

## Boundaries

Research is manually requested outside the app. No autonomous scraping, cron jobs,
crawlers, external browser automation, auto-apply, recruiter messaging, email/calendar
automation, extensions, salary prediction, ML recommendations, embedded paid LLM APIs,
recruiter CRM, public profiles/accounts, teams, billing, native app or push notifications.
No decorative analytics. Stable LinkedIn umbrella; targeted CV positioning.

## Actors

- Moshe: final decisions, overrides, applications, career priorities and answers.
- AI researcher: on-demand public research, evidence-based fit, drafting and mentoring.
- Coding agent: implement and maintain the approved software without redefining strategy.
