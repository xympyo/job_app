# Implementation plan

1. Documentation and canonical profile; capture full original handover.
2. Vite/React/Tailwind, routing, constants, validators, local persistence.
3. SQL migrations, per-user RLS, transactional operations and Supabase adapter.
4. Email/password authentication, protected routes and error/loading handling.
5. Dashboard, Inbox, responsive list/detail, company/job/source CRUD and search/filter.
6. Editable explainable fit and CV library.
7. Application creation/snapshot, stages/history, actions, outcomes, events and questions.
8. Validated research import, preview, duplicate decisions and export.
9. Automated domain/UI/database checks and manual browser responsive QA.
10. Production build, deployment instructions, current-state handoff and local preview.

Account-dependent cloud connection is the final boundary, not an early development blocker.
